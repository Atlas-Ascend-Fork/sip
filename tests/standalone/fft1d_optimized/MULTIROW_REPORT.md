# FFT 多行 tile 与分段流水

连续一维原生后端按实际长度安排 UB 中的数据区，扩大每个 tile 处理的行数。二次幂保留原寄存器/radix4 蝶形；mixed 保留专用 radix3/5/7 蝶形及较大质数的对称算法，将行维度加入向量索引。旋转因子保持完整表，不新增压缩与重建。

| 分支 | 长度 | 调度 |
|---|---|---|
| 二次幂 C2C | 32～256 | 满足原流水阈值的正向扩大 tile；逆向保留原 tile |
| 二次幂 C2C | 512～4096 | 满足原流水阈值时，多行 tile、三数据区轮换 |
| 二次幂 R2C/C2R | 32～512 | 扩大 tile，保留寄存器调度 |
| 二次幂 R2C/C2R | 1024～8192 | 满足原流水阈值时，多行 tile、三数据区轮换 |
| mixed C2C | ≤2944 | 动态 UB、多行蝶形、四数据区双缓冲 |
| mixed C2C | 2976～3808 | 完整表三数据区，两行 tile |
| mixed C2C | 3840～6720 | 完整表三数据区，单行 tile |
| mixed C2C | 6752～8192 的合法 mixed 长度 | 两数据区动态布局，单 tile 完成写出后复用 |
| mixed R2C/C2R | ≤5312 | 紧凑实数工作区、动态 UB、四数据区双缓冲 |
| mixed R2C/C2R | 5344～6688 | 紧凑工作区、完整表三数据区轮换 |
| mixed R2C/C2R | 6720～8192 | 紧凑工作区、四数据区单行 |

mixed 仅作用于原公共规划器已支持的非二次幂、32 倍数长度，保留实数 N≤1024 的原 DFT 选路。batch 范围为 1～8192。C2C 支持正逆向，实数为 R2C 正向/C2R 逆向。公共 mixed 的一维调用及二维方阵复用轴统一使用新调度，删除原固定容量行内核和新旧调度选择参数。二次幂的二维选路、转置实现、外部后端选择及范围外回退保持原状。

四数据区是两个 tile 的 a/b 工作区；三数据区分别承担当前输入、计算临时区和下一 tile 预取。写出完成后才复用输出区，尾 tile 按每核剩余行数裁剪。mixed 使用 212 KiB 预算，C2C 行跨度为 2N+128 个 float，实数为 N+128 个 float。

## 验证

Ascend950DT 上分三轮完成40组测试请求（26正式对照组、14功能组，含重复控制），共31284完整ACL Event、132输出，全部FP64相对L2<1e-3，最大2.0759343391107836e-7。首轮26组、容量扩展10组、两区单行计算及实数边界4组。不同轮次的同shape结果不拼最佳值。

主机原524288选路组合及204组多行描述符组合通过；mixed对247个合法长度、三种pass共741组检查容量、对齐、最大行数和选路，原768规划网格及11反例也通过。主机检查不替代设备验证，未宣称所有方向/batch组合上板。

## 公共 mixed 路径完全替换（r4）

删除固定容量 Rows<128/512/2048/8192>、旧 key 0～3、旧实数边界实现及 mixed multirow 选择参数。一维与二维方阵复用轴统一按容量选路，保留新版所需的单行蝶形公式。五个新 key 19/21/22/25/26 的设备 .text 均与 r3 相同，旧 key 不再生成。

在 Ascend950DT、NPU5/CPU5 上补测7组二维方阵，外部 batch=1。对照为本 PR 更新前 0a5caaf 对应的 r3 库，候选为完整替换后库。4组正式、3组功能，共4818 Event、22输出全部通过，最大 FP64 相对 L2 为 2.952e-7。正式项两轮反序、每版每轮10预热和300完整 ACL Event，无 profiler；各组前后目标卡均无其他进程，其他卡有任务，不宣称整机独占。
