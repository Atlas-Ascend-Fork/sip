# Ascend950 FFT 优化验证与已有性能结果

当前范围：水平连续 FP32/complex64，二次幂 N=32～8192；一维 batch=N，二维 batch=1 的 N×N 方阵。
C2C 正逆向、R2C 正向、C2R 逆向的全部目标尺寸均启用，不按单点性能退化回退。二维复用原有转置流程。

## 当前分支验证

- Ascend950、CANN 9.2.0-beta.2，Release 构建通过（`NO_WERROR=ON`）。
- 一维及二维9个目标尺寸、4种算子/方向、原版与候选版，共144/144组随机输入冒烟通过；最大相对L2为2.762502632e-7，FP64 NumPy golden，阈值1e-3。
- 校验实际kernel选路：二维C2C两个轴均启用；二维实数轴batch=N、复数轴batch=N/2+1均启用。
- 主机测试覆盖524288种一维选路组合、二维适用范围与不同核数下的UB用量；两项布局及系数边界测试通过。
- 扩展正式测试按用户要求停止，已产生的部分计时不用于本报告；不宣称完整回归套件完成。原地与非目标回退的完整用例保留在测试工具中，当前分支未完成这些新增设备回归。

基线为上游 `5a3b1e31`；batch=N，正反测试顺序各300个ACL Event样本，每版合并600个样本取中位数。
不包含Plan、分配、H2D/D2H，不启用profiler。该轮156组验证中154组启动时存在其他进程。
